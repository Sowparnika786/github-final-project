# Simple Interest Calculator

A simple web application to calculate simple interest based on the principal amount, annual interest rate, and time period.

## 🧮 Formula Used

The calculator uses the standard simple interest formula:

$$A = P(1 + rt)$$

Where:
* **$A$** = Total Amount (Principal + Interest)
* **$P$** = Principal Amount
* **$r$** = Annual Interest Rate (as a decimal)
* **$t$** = Time (in years)

## 🚀 Features
* **Quick Computation:** Instantly calculates the interest and total amount.
* **User-Friendly:** Simple input fields for easy navigation.
* **Responsive:** Works perfectly on both desktop and mobile browsers.
